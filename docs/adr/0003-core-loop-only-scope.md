# Core loop only for this build phase

The legacy Hacker Experience game also had clans, missions, university/certifications, a forum, a police/FBI bounty system, and periodic round resets. We deliberately excluded all of these from this effort: only the Computer/Hardware/Software/Process/Hack/currency/Log core is in scope. Each excluded system is a large feature in its own right and would blow up this map before the core loop even works end to end.

## Consequences

There is currently no in-game consequence for leaving a Log undeleted beyond the Target seeing it directly (no police/FBI escalation). Retaliation, reputation, and organized play (clans, missions) don't exist yet. Revisiting any of these is a new Wayfinder map, not a resumption of this one.
